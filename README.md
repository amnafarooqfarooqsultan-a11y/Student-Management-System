# AURELITH Academy 

### Student Management System

AURELITH Academy is a web-based Student Management System designed to organize student information, display class details, showcase class teacher profiles, and present upcoming academy events.

The project focuses on building an interactive academy portal while applying core JavaScript concepts.

##  Features

- **Student Records:** Display student names and information.
- **Class Information:** Organize student records according to their classes.
- **Email Details:** Display student email information.
- **Class Teachers:** Showcase class teacher profiles.
- **Upcoming Events:** Present upcoming academy events.
- **Interactive Interface:** Use JavaScript to create dynamic website content.

##  Technologies Used

- HTML5
- CSS3
- JavaScript

##  JavaScript Concepts Applied

- **DOM Manipulation:** Displaying and updating website content dynamically.
- **Classes and Objects:** Structuring student information.
- **Arrays and Array Methods:** Organizing and processing student records.
- **Event Listeners:** Handling user interactions.
- **Loops and Conditional Statements:** Processing data and controlling application behavior.

##  Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.
4. Explore student records, class teacher profiles, and upcoming events.

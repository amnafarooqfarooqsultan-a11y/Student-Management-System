# AURELITH Academy 

### Student Management System

AURELITH Academy is a web-based Student Management System designed to organize student information, manage attendance records, display class details, and provide information about class teachers and upcoming events.

The project focuses on building an interactive academy portal while applying core JavaScript concepts and DOM manipulation techniques.

##  Features

- **Student Attendance:** View and manage student attendance records.
- **Student Records:** Organize student information, including names, classes, and email details.
- **Class Information:** Keep student records organized according to their respective classes.
- **Class Teachers:** Display profiles of class teachers.
- **Upcoming Events:** Present upcoming academy events in an organized section.
- **Interactive Interface:** Use JavaScript to make the website interactive and dynamically update content.

##  Technologies Used

- HTML5
- CSS3
- JavaScript

##  JavaScript Concepts Applied

This project focuses on strengthening practical JavaScript skills, including:

- **DOM Manipulation:** Dynamically displaying and updating website content.
- **Classes and Objects:** Structuring student and related information.
- **Arrays:** Storing and organizing student records.
- **Array Methods:** Working with array functions to process and manage data.
- **Event Listeners:** Handling user interactions.
- **Loops and Conditional Statements:** Processing records and controlling application behavior.

##  Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or run it using the Live Server extension.
4. Explore the student records, attendance section, class teacher profiles, and upcoming events.
